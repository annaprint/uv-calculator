# Дизайн: Калькулятор УФ-печати для менеджеров

**Дата:** 2026-04-09  
**Компания:** Типография «Сити Принт», Екатеринбург  
**Проект:** `prices/` — локальное веб-приложение  

---

## 1. Цель

Инструмент для менеджеров, позволяющий быстро рассчитать стоимость УФ-печати по двум направлениям:

1. **Листовая продукция** — печать на жёстких материалах (картон, пенокартон, пластик и др.)
2. **Сувенирная продукция** — печать на готовых изделиях из каталога (ручки, ежедневники, power bank'и и др.)

Администратор ведёт справочники цен через интерфейс. Менеджер выбирает параметры, получает разбивку стоимости и может сформировать КП.

---

## 2. Стек

- **Backend:** Node.js + Express
- **База данных:** SQLite (файл `data/uv.db`)
- **Frontend:** HTML + vanilla JS (без фреймворков)
- **Импорт каталога:** xlsx (парсинг Excel-файла `kopi/catalog.xlsx`)

## 4. Схема базы данных

### `sheet_materials` — материалы для листовой печати
| Поле | Тип | Описание |
|---|---|---|
| id | INTEGER PK | |
| name | TEXT | Название (напр. «Картон») |
| price_per_sqm | REAL | Базовая цена ₽/м² (без тиражных ступеней) |
| active | INTEGER | 1 = активен |

### `sheet_tiers` — тиражные ступени для листовой печати
| Поле | Тип | Описание |
|---|---|---|
| id | INTEGER PK | |
| min_sqm | REAL | От, м² (порог ступени) |
| price_per_sqm | REAL | Цена надпечатки ₽/м² на этой ступени |

> Ступени применяются к **общей площади** (ширина × высота × тираж). Выбирается наибольшая подходящая ступень (max min_sqm ≤ total_sqm).

### `souvenir_prices` — тарифы сувенирной печати
| Поле | Тип | Описание |
|---|---|---|
| id | INTEGER PK | |
| product_type | TEXT | Тип товара (напр. «Ручки (пластик)») |
| qty_up_to_29 | REAL | Фиксированная сумма за весь тираж до 29 шт. (не за штуку) |
| qty_from_30 | REAL | |
| qty_from_100 | REAL | |
| qty_from_500 | REAL | |
| qty_from_1000 | REAL | |

### `catalog_items` — товары из импорта Excel
| Поле | Тип | Описание |
|---|---|---|
| id | INTEGER PK | |
| article | TEXT | Артикул (напр. «3005.01») |
| name | TEXT | Название товара |
| category | TEXT | Категория |
| souvenir_price_id | INTEGER FK | Ссылка на тарифную ступень |

### `quotes` — сохранённые расчёты / КП
| Поле | Тип | Описание |
|---|---|---|
| id | INTEGER PK | |
| created_at | TEXT | Дата создания |
| type | TEXT | «sheet» или «souvenir» |
| params | TEXT | JSON с параметрами расчёта |
| result | TEXT | JSON с итогом |
| kp_text | TEXT | Текст КП |

## 6. Логика расчёта

### 6.1 Листовая продукция

```
total_sqm = (width_mm / 1000) × (height_mm / 1000) × qty

# Если материал свой (не заказчика):
material_cost = material.price_per_sqm × total_sqm

# Надпечатка (по тиражным ступеням):
tier = max ступень где min_sqm ≤ total_sqm
print_cost = tier.price_per_sqm × total_sqm

# Опции (надбавки от базовой стоимости печати):
base_print_cost = print_cost
if uv_varnish: print_cost += base_print_cost × 0.30
for each relief_layer: print_cost += base_print_cost × 0.30

# Срочность применяется ко всей сумме:
subtotal = material_cost + print_cost   # или только print_cost при материале заказчика
if urgent: subtotal += subtotal × 0.30

total = subtotal
price_per_unit = total / qty
```

### 6.2 Сувенирная продукция

```
# Выбор тиражной ступени:
if qty < 30:
    base = qty_up_to_29           # фиксированная сумма за весь тираж
else:
    price_per_unit = подходящая колонка qty_from_XX
    base = price_per_unit × qty

# Опции (надбавки от базы):
base_before_options = base
if uv_varnish: base += base_before_options × 0.30
for each relief_layer: base += base_before_options × 0.30

# Срочность:
if urgent: base += base × 0.30

total = base
price_per_unit = total / qty
```

## 7. Интерфейс менеджера (`index.html`)

Две вкладки: **Листовая продукция** и **Сувенирная продукция**.

### Листовая вкладка
- Чекбокс «Материал заказчика — только надпечатка» (при активации поле материала недоступно)
- Выпадающий список материала (из `sheet_materials`)
- Поля: ширина мм, высота мм, тираж шт.
- Автоматически показывает общую площадь и применённую ступень
- Чекбоксы опций: УФ-лак (+30%), рельефный белый (+30% за слой)
- Переключатель срочности: Стандарт / Срочно (+30%)
- Кнопка «Рассчитать»
- Блок результата: базовая печать, материал (если не заказчик), каждая надбавка отдельной строкой, итого, цена за штуку
- Кнопка «Сформировать КП»

### Сувенирная вкладка
- Поле поиска товара (фильтр каталога)
- Выпадающий список товаров из каталога
- Поле количества + автоматическая подсказка применённой ступени
- Чекбоксы опций: УФ-лак, рельефный белый
- Переключатель срочности
- Кнопка «Рассчитать»
- Блок результата аналогично листовой вкладке

## 8. Интерфейс администратора (`admin.html`)

Боковое меню с разделами:

1. **Листовые материалы** — таблица с полями «Название» и «Базовая цена ₽/м²», добавление/удаление строк, кнопка сохранения
2. **Ступени листовой печати** — таблица «От, м²» + «₽/м²», добавление/удаление, сохранение
3. **Сувенирная печать** — таблица с типами товаров и пятью тиражными колонками (до 29, от 30, от 100, от 500, от 1000), добавление/удаление
4. **Каталог товаров** — кнопка загрузки Excel, дата последнего импорта, количество товаров; каждая позиция каталога привязывается к типу из `souvenir_prices`
5. **Сохранённые КП** — список, просмотр, удаление

---

## 9. Импорт каталога из Excel

- Файл: `kopi/catalog.xlsx` (133+ товара)
- Столбцы: Артикул, Название, Категория, Фото (URL)
- При импорте: читаем xlsx, обновляем `catalog_items` (upsert по артикулу)
- Привязка к `souvenir_prices` — через поле категории или вручную в админке
