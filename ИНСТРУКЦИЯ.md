# Инструкция по запуску и использованию калькулятора УФ-печати

---

## Часть 1. Первый запуск

### 1.1 Установить зависимости

Открой Терминал, вставь команду:

```bash
cd "/Users/annakorotkih/Desktop/Claude Code Lab/prices" && npm install
```

Подожди, пока установятся пакеты (займёт ~30 секунд).

---

### 1.2 Заполнить базу начальными ценами

```bash
node seed.js
```

В ответ должно появиться: `Seed complete.`

Это создаёт в базе:
- 5 материалов (Картон, Пенокартон, Пластик 5 мм, Алюмокомпозит, Оргстекло)
- 5 тиражных ступеней листовой печати
- 8 типов сувенирной продукции (Ручки, Ежедневники, Power Bank, Флешки, Термокружки)

> Цены примерные — их можно поменять через панель администратора.

---

### 1.3 Запустить сервер

```bash
node server.js
```

В ответ должно появиться: `Server running on http://localhost:3001`

> Терминал с сервером должен оставаться открытым. Чтобы остановить сервер — нажми `Ctrl+C`.

---

### 1.4 Загрузить каталог товаров

1. Открой браузер, перейди на: **http://localhost:3001/admin.html**
2. В левом меню нажми **«Каталог товаров»**
3. Нажми кнопку **«Загрузить catalog.xlsx»**
4. Выбери файл: `/Users/annakorotkih/Desktop/Claude Code Lab/kopi/catalog.xlsx`
5. Под кнопкой появится: «Импортировано: 133 товара»

---

### 1.5 Привязать товары к типам сувенирной печати

Это нужно, чтобы калькулятор знал, по какой цене считать конкретный товар.

1. Ты находишься в разделе **«Каталог товаров»**
2. Для каждого товара в крайней правой колонке есть выпадающий список **«Тип печати (привязка)»**
3. Выбери нужный тип:
   - Ручки → «Ручки (белый пластик)» или «Ручки (цветной пластик)» и т.д.
   - Ежедневники → «Ежедневник А5» или «Ежедневник А4»
   - Power Bank → «Power Bank»
   - И т.д.
4. Привязка сохраняется **сразу автоматически** — никаких кнопок нажимать не нужно

> Товары без привязки в калькуляторе не считаются. Если менеджер выберет непривязанный товар — увидит подсказку «настройте в панели администратора».

## Часть 3. Калькулятор для менеджеров

Открой: **http://localhost:3001**

### Расчёт листовой продукции (вкладка «Листовая продукция»)

1. Если материал предоставляет заказчик — поставь галочку **«Материал заказчика»** (тогда считается только надпечатка)
2. Выбери **материал** из списка (если материал ваш)
3. Введи **ширину** и **высоту** в миллиметрах
4. Введи **тираж** (количество штук)
5. В серой плашке автоматически появится общая площадь и применяемая тиражная ступень
6. При необходимости отметь опции:
   - **УФ-лак** — +30% к стоимости надпечатки
   - **Рельефный белый** — укажи количество дополнительных слоёв, каждый +30%
7. Выбери срочность:
   - **Стандарт** — 3–5 рабочих дней
   - **Срочно** — 1–2 дня, +30% к итоговой сумме
8. Нажми **«Рассчитать →»**
9. Появится разбивка по статьям и итоговая сумма

---

### Расчёт сувенирной продукции (вкладка «Сувенирная продукция»)

1. В поле **«Поиск товара»** начни вводить название (например, «ручка» или «power») — список отфильтруется
2. Выбери товар из выпадающего списка
3. Введи **количество** штук
4. В серой плашке появится применяемая тиражная ступень
5. При необходимости отметь опции (УФ-лак, рельефный белый, срочность)
6. Нажми **«Рассчитать →»**
7. Появится разбивка и итог

---

### Формирование КП

После расчёта нажми **«Сформировать КП»** — откроется окно с текстом коммерческого предложения. КП автоматически сохранится в базе данных.

Все сохранённые КП можно посмотреть в панели администратора: **http://localhost:3001/admin.html** → **«Сохранённые КП»**

## Часть 4. Панель администратора

Открой: **http://localhost:3001/admin.html**

### Листовые материалы
- Добавить материал: введи название и цену ₽/м², нажми **«+ Добавить»**
- Изменить цену: отредактируй прямо в таблице, нажми **«Сохранить изменения»**
- Удалить: нажми **✕** напротив материала

### Ступени листовой печати
- Ступень — это минимальная площадь (в м²), при которой применяется данная цена
- Применяется наибольшая подходящая ступень
- Например: тираж 50 листов А3 = ~1,6 м² → применится ступень «от 0 м²»
- Добавить, изменить, удалить — аналогично материалам

### Сувенирная печать
- Таблица с ценами по тиражным ступеням для каждого типа товара
- **До 29 шт.** — фиксированная сумма за весь тираж (не за штуку!)
- **От 30, от 100, от 500, от 1000** — цена за 1 штуку
- Добавить, изменить, удалить — аналогично

### Каталог товаров
- Импорт из Excel (повторный импорт обновляет существующие товары)
- Привязка товаров к типам сувенирной печати

### Сохранённые КП
- Список всех сформированных коммерческих предложений
- Можно удалить ненужные

## Возможные проблемы

**«Сервер не отвечает» / страница не открывается**
→ Проверь, запущен ли сервер в терминале. Если нет — запусти `node server.js`

**Товар в калькуляторе не считается (ошибка про администратора)**
→ Зайди в admin.html → Каталог товаров → привяжи товар к типу печати

**Хочу сбросить все цены к начальным**
→ Выполни `node seed.js` заново (удалит текущие цены и вставит начальные)
